# .NET Framework – Part 2 Projects

This repository includes a collection of **C# exercises** and example projects created within the **.NET Framework**.  
Each subfolder corresponds to a standalone task designed to develop programming discipline, object-oriented thinking, and clean architectural design.

---

## Repository Contents

- `asp/` – A beginner-level **ASP.NET MVC** application demonstrating controller actions, routing, and view integration.  
- `final/` – A complete project combining principles of OOP, data validation, and structured logic to form a cohesive application.  
- `method/` – A group of exercises focusing on **method construction**, argument passing, and overloading for reusability.  
- `operators/` – Short, targeted programs showcasing the behavior of arithmetic, comparison, and logical operators.  
- `polymorphism/` – Practical examples of **inheritance**, abstract classes, and interface implementation.  
- `portfolyo/` – A final compilation project that unites all assignments into a portfolio-style demonstration.

> The structure of this repository directly corresponds to its folder organization for easy access.
